## CyCodeIDE 0.2.4 — Windows x64

Version de développement avec assistant CyMCPSDK natif et automatisation CLI/MCP partagée.

- Ouvrez **Affichage → Assistant** pour les réponses progressives, l’annulation et la restauration de l’historique privé.
- Chat, terminal et clients MCP externes utilisent les mêmes documents Core et transactions contrôlées. Lecture seule par défaut ; les préférences ont une autorisation distincte.
- Huit outils IDE exposent onglets, sélection, panneaux et préférences communes de zoom/police/minicarte. Les commandes CLI existantes et la migration explicite des anciennes tâches sont conservées.
- Inclut les améliorations récentes des menus, de l’arborescence, de la recherche, du zoom partagé, de la minicarte et de la gouttière des points d’arrêt.
- CyMCPSDK natif remplace CyToolsCore et le serveur MCP Python.

Choisissez `CyCodeIDE-0.2.4-windows-x64-setup.exe` pour une installation par utilisateur, ou extrayez entièrement `CyCodeIDE-0.2.4-windows-x64.zip` puis lancez `CyCodeIDE.exe`. Conservez tous les fichiers livrés. Les empreintes SHA-256 figurent dans `SHA256SUMS.txt`. Les archives sources de GitHub contiennent le code source.

**Validation :** compilation Windows Release, dix vérifications Python et essais isolés CLI/MCP/chat/interface masquée de production réussis avec fournisseur local simulé. Droits, vraies actions IDE, modifications non enregistrées, sauvegarde explicite, annulation/restauration et lecture Unicode par morceaux ont été vérifiés. Gitleaks et contrôles du paquet/empreintes réussis. Installateur, comptes fournisseurs réels, remplacement/redémarrage en ligne, machine propre et Linux/macOS restent non vérifiés. Binaires non signés. GitHub Actions reste désactivé.
