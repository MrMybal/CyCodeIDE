## CyCodeIDE 0.2.3 — Windows x64

First standalone CyCodeIDE release, separated from the historical CyCode desktop application.

- Progressive native analysis, explicit batches/checkpoints, C++ inspections and guarded shared change history.
- Shared Reader/CyUI paged UTF-8 editing, full-document saves and explicit native recovery.
- CyCodeIDE application updates: optional startup checks, explicit verified download/resume and install/restart, with a dedicated helper and per-user installation identity.
- Complete English/French offline manual, native CLI and VCS providers, isolated Python/MCP, fonts and app-local MSVC runtime.

Choose `CyCodeIDE-0.2.3-windows-x64-setup.exe` for per-user installation, or extract the entire `CyCodeIDE-0.2.3-windows-x64.zip` and run `CyCodeIDE.exe`. SHA-256 values are in `SHA256SUMS.txt`. GitHub's source archives are source code, not the portable application.

**Validation:** Windows Release production compilation and source/data/package/hash checks pass, with native tests disabled. Application, helper and installer execution, real online replacement/restart/recovery, clean-machine acceptance and Linux/macOS were not tested under the current local execution restrictions. Binaries are unsigned. GitHub Actions remain disabled.
