## CyCodeIDE 0.2.4 — Windows x64

Development release with the native CyMCPSDK assistant and shared CLI/MCP automation.

- Open **View → Assistant** for streamed conversations, cancellation and private history restoration.
- Chat, terminal and external MCP clients use the same live Core documents and guarded transactions. Read-only access is the default; editor preferences have a separate grant.
- Eight IDE tools expose document tabs, selection, panels and shared zoom/font/minimap preferences. Existing CLI commands and explicit legacy-job migration remain available.
- Includes the recent menu, project-tree, search, shared zoom/minimap and breakpoint-gutter presentation improvements.
- CyToolsCore and the Python MCP server are replaced by native CyMCPSDK.

Choose `CyCodeIDE-0.2.4-windows-x64-setup.exe` for per-user installation, or extract the entire `CyCodeIDE-0.2.4-windows-x64.zip` and run `CyCodeIDE.exe`. Keep all accompanying files. SHA-256 values are in `SHA256SUMS.txt`. GitHub’s source archives contain source code.

**Validation:** Windows Release compilation, ten Python checks and isolated production CLI/MCP/chat/hidden-GUI acceptance with a local simulated provider passed. Rights, actual IDE actions, unsaved edits, explicit save, cancellation/restoration and chunked Unicode reads were checked. Gitleaks and package/hash checks passed. Installer execution, real provider accounts, online replacement/restart, clean-machine acceptance and Linux/macOS remain unverified. Binaries are unsigned. GitHub Actions remain disabled.
