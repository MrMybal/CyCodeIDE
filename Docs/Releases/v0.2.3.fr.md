## CyCodeIDE 0.2.3 — Windows x64


Première publication autonome de CyCodeIDE, séparée de l’ancienne application de bureau CyCode.

- Analyse native progressive, lots et points de reprise explicites, inspections C++ et historique partagé contrôlé.
- Édition UTF-8 paginée Reader/CyUI, enregistrement intégral et récupération native explicite.
- Mises à jour propres à CyCodeIDE : vérification facultative au démarrage, téléchargement/reprise vérifiés, installation/redémarrage explicites et auxiliaire dédié.
- Manuel hors ligne anglais/français, CLI et providers VCS natifs, Python/MCP isolé, polices et runtime MSVC embarqués.

Utiliser `CyCodeIDE-0.2.3-windows-x64-setup.exe` pour une installation par utilisateur, ou extraire tout `CyCodeIDE-0.2.3-windows-x64.zip` et lancer `CyCodeIDE.exe`. Les empreintes SHA-256 figurent dans `SHA256SUMS.txt`. Les archives automatiques des sources GitHub ne sont pas l’application portable.

**Validation :** compilation Windows Release et contrôles des sources, données, paquets et empreintes réussis, tests natifs désactivés. Application, auxiliaire et installateur non exécutés ; remplacement/redémarrage/récupération réels en ligne, machine propre et Linux/macOS non validés sous les restrictions locales actuelles. Binaires non signés. GitHub Actions restent désactivées.
