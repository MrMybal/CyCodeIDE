## CyCodeIDE 0.2.5 — Windows x64

Version de développement avec MCP local Free et profils d’accès persistants.

- Connecter une IA externe par URL MCP seule avec Free, le profil par défaut. Lecture et modification sans jeton ni confirmation supplémentaire par opération. Schémas, révisions, limites du projet et sauvegardes explicites restent appliqués.
- Conserver les choix explicites Free, Local contrôlé, Jeton seul ou Protégé. Protégé exige son jeton et les droits de l’hôte. Les configurations sans choix migrent vers Free ; enregistrer les préférences de l’éditeur conserve les réglages MCP.
- Activer/désactiver le MCP local dans son panneau et copier l’adresse, la configuration HTTP directe ou la configuration CLI stdio existante. Les points d’accès écoutent uniquement sur `127.0.0.1`.
- Chat, CLI et MCP externe conservent les mêmes documents Core et transactions. Core 0.1.6 et CyMCPSDK 0.7.2 compilés depuis les sources locales.

Choisir `CyCodeIDE-0.2.5-windows-x64-setup.exe` pour une installation par utilisateur, ou extraire entièrement `CyCodeIDE-0.2.5-windows-x64.zip` puis lancer `CyCodeIDE.exe`. Conserver tous les fichiers livrés. Les empreintes SHA-256 figurent dans `SHA256SUMS.txt`.

**Validation :** compilation Windows Release, dix vérifications Python et quatorze vérifications isolées CLI/MCP/chat/interface masquée de production réussies avec fournisseur local simulé. Lecture/modification Free, refus des jetons en Protégé, quatre profils, validation des arguments, migration/persistance, CLI stdio et annulation/restauration du chat ont été exercés. Gitleaks et contrôles du paquet/empreintes/liens réussis. Installateur, comptes fournisseurs réels, remplacement/redémarrage en ligne, machine propre et Linux/macOS restent non vérifiés. Binaires non signés. GitHub Actions reste désactivé.
