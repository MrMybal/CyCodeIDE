## CyCodeIDE 0.2.5 — Windows x64

Development release with Free local MCP access and persistent access profiles.

- Connect an external assistant by MCP URL alone in Free, the default profile. Reads and writes need no token or additional operation confirmation. Schemas, document revisions, workspace boundaries and explicit saves remain enforced.
- Keep explicit Free, Local controlled, Token only or Protected choices. Protected requires its token and host grants. Unset configurations migrate to Free; saving editor preferences preserves MCP settings.
- Enable/disable local MCP from its panel, and copy the address, direct HTTP configuration or existing CLI stdio configuration. All endpoints bind only to `127.0.0.1`.
- Chat, CLI and external MCP retain the same live Core documents and transactions. Updated to Core 0.1.6 and CyMCPSDK 0.7.2 from local source.

Choose `CyCodeIDE-0.2.5-windows-x64-setup.exe` for per-user installation, or extract the entire `CyCodeIDE-0.2.5-windows-x64.zip` and run `CyCodeIDE.exe`. Keep all accompanying files. SHA-256 values are in `SHA256SUMS.txt`.

**Validation:** Windows Release compilation, ten Python checks and fourteen isolated production CLI/MCP/chat/hidden-GUI checks passed with a local simulated provider. Free reads/writes, Protected token rejection, all profiles, argument validation, migration/persistence, CLI stdio and chat cancellation/restoration were exercised. Gitleaks and package/hash/link checks passed. Installer execution, real provider accounts, online replacement/restart, clean-machine acceptance and Linux/macOS remain unverified. Binaries are unsigned. GitHub Actions remain disabled.
