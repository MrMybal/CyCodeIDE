## Preserved and pending

66 C++ presentation/host units, 12 UI headers/helpers and 10 UI fixture sources
are owned here. Core's update implementation remains native and unique; detail
headers used by this host are explicitly under cycode/update/detail. The stdio
service, socket envelope and native transactions have one Core owner.

The existing offline manual and public SDK schemas remain canonical in Core.
The IDE build stages its selected manifest/facade, locales/fonts/notices, native
CLI and six bundled providers. It copies no local workspace/settings tree and
keeps the actual HTML reader rather than Markdown links.

Reader currently shares native utility ownership; its richer document/search/
bridge model is a later Engine integration lot. Source/API 1 compatibility is
preserved, without pretending that a dependency change merged those sessions.

Before publishing a CyCodeIDE release, migrate installer/update asset names,
repository identity and distribution allow-lists, then validate installed and
portable layouts. The historical updater is disabled in this development build.
Archived desktop/release workflows remain in .github/legacy for that migration.
Advanced C++ project invalidation/refactoring and measured optimization are Core
follow-up lots. The full rationale and commands are in Core's
app/Docs/CoreExtraction.md and the new bilingual native-core manual page.
