# CyCodeIDE

Native C++20 IDE, extracted from CyCode 0.2.3. **Development snapshot**: the
interface consumes the existing CyCode Core; this is not a new released version.

![CyCode](icons/CyCode.png)

CyCode owns documents, compiler adapters, semantic language services, transactions,
plugins and native contracts. This repository owns the SDL/OpenGL/CyUI interface,
window lifecycle, panels, themes, keymaps and presentation resources. Reader
provides the shared graphical editor API 1 and consumes CyCode's native utilities.
The executable is now named `CyCodeIDE`; its internal target remains `CyCode`
while existing UI validation scripts are migrated.

## Build

```sh
python app/scripts/build.py --fetch
```

CMake 3.24+, C++20, Windows Visual Studio 2022 or Linux/macOS toolchains are
required. Dependency source revisions are locked. The private CyCode repository
requires available Git authentication; never put a token in source/CLI examples.
For unpublished companion branches, select explicit checkouts:

```sh
python app/scripts/build.py --core-root <CyCode> --editor-root <CyCodeReader> --fetch
```

The build configures native tests OFF and never starts the app. The actual
executable and shared facade/resources are staged in runtime/build/app/Release
on Windows, runtime/build/app on single-configuration platforms. Core's offline
CyDoc reader is generated by default and remains available without a server.
`--without-documentation` is an explicit compile-only option, not a release build.
The Core facade/manifest are copied from the dependency at build time; no second
operation registry is maintained here. No local project/settings data is copied.

## Current limits

Windows compile validation is recorded in Docs/Extraction.md. Runtime checks
remain suspended locally while the existing antivirus removals are unresolved.
Linux/macOS compilation and post-extraction GUI acceptance remain to run.
Installer/update naming, distribution automation and README/Pages links must be
adapted before the first CyCodeIDE release. Historical desktop workflows are
preserved under .github/legacy and are deliberately inactive during extraction.
The updater still uses the historical CyCode identity and must not be published
as a CyCodeIDE installer until its migration is verified. GPL-3.0-only; see LICENSE.
